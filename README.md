# Условия и функции в Python

> Небольшой учебный пример Python: функция, условные ветвления и вывод результата.

**Стек:** Python · стандартная библиотека

## Пример

`main.py` демонстрирует функцию `f(n)` и условные ветвления для сравнения с числом 5.

```bash
python main.py
```

В текущем примере вызывается `f(10)` и печатается `0`. Это небольшой учебный фрагмент.
